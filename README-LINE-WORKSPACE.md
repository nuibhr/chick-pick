# LINE Mini App และพื้นที่ผู้จัด (สถานะทดลอง)

## เปิดทดลองในเครื่อง

1. ใช้ Node.js 22 ขึ้นไป แล้วรัน `npm install` และ `npm run dev` ในโฟลเดอร์โปรเจกต์
2. เปิด `http://localhost:3000/` เพื่อตั้งรหัสผ่านผู้จัดครั้งแรก (12–128 ตัวอักษร) และจัดการก๊วน
3. เปิด `http://localhost:3000/miniapp` เพื่อดูหน้าผู้เล่นบนมือถือ หน้าแคตตาล็อกดูได้แม้ยังไม่เชื่อม LINE
4. เปิด `http://localhost:3000/?admin=1` เพื่อดูบัญชี สูตรค่าคอม และใบแบ่งรายได้ ใช้รหัสผ่านเดียวกัน
5. เงินสดให้ผู้จัดยืนยันเอง; เงินโอนให้ผู้เล่นแนบสลิปผ่าน Mini App แล้วแอดมินตรวจภาพกับยอดเข้าบัญชีจริงก่อนอนุมัติ รายการที่ยังไม่อนุมัติไม่เข้าฐานแบ่งค่าคอม

6. ในหน้า Workspace → ตั้งค่า ใส่ธนาคาร ชื่อบัญชี และเลขบัญชีเพื่อให้รายการจองใหม่เห็นปลายทางรับโอนของตัวเอง รายการเก่ายังคงข้อมูลบัญชีที่บันทึกไว้ตอนจอง ฟังก์ชันนี้มีไว้ซ้อม workflow ในเครื่องเท่านั้น

## เชื่อม LINE เพื่อทดสอบการจองผ่านบัญชีจริง

- สร้าง LINE Login channel และ LIFF app ของตนเองใน LINE Developers ตั้ง Endpoint URL เป็น HTTPS URL ของแอปที่ลงท้าย `/miniapp` และเปิดสิทธิ์ `openid` กับ `profile`
- ใส่ `LINE_CHANNEL_ID` (Channel ID ไม่ใช่ Channel Secret) และ `VITE_LIFF_ID` ใน `.env` ของเซิร์ฟเวอร์ แล้วรีสตาร์ต
- เปิด Endpoint ผ่าน LINE บนมือถือ กดเชื่อม LINE แล้วทดลองจอง ผู้เล่นจะเห็นเฉพาะการจองที่ผูกกับ LINE user ID ของตน
- เซิร์ฟเวอร์รับ raw ID token ผ่าน Bearer header และตรวจที่ LINE ทุกครั้ง ไม่เชื่อข้อมูลโปรไฟล์หรือ user ID ที่เบราว์เซอร์ส่งมาเอง

- ผู้เล่นเห็นเพื่อนในก๊วนก่อน Join ได้จากรายชื่อการจองที่ยังไม่ยกเลิก เฉพาะผู้ที่เปิด “แสดงโปรไฟล์ในก๊วนที่จอง” ในหน้าโปรไฟล์เท่านั้นจะแสดงชื่อและรูป LINE; ผู้ที่ปิดจะแสดงเป็นจำนวนคนซ่อนโปรไฟล์ ไม่มี LINE user ID, ข้อมูลจ่ายเงิน หรือสลิปในข้อมูลสาธารณะ การจองยังไม่ใช่การยืนยันตัวจริงว่าจะมาสนาม

การจอง LINE และการตรวจสลิปเปิดเฉพาะโหมด development เพื่อทดลองขั้นตอน ไม่มีการตัดบัตรหรือโอนค่าคอมจริง OCR เป็นเพียงตัวช่วยอ่านข้อมูลและยังไม่มี endpoint ที่ตั้งค่าไว้ ดูสัญญา API ใน README-OCR.md โหมด production ปิด API การจอง/บัญชีไว้จนกว่าจะมีฐานข้อมูลกลาง สิทธิ์ผู้จัดตามคลับ การสำรองและดูแลภาพสลิป และการยกเลิก/คืนเงินสำหรับรายการที่อนุมัติแล้ว อย่าใช้ URL สาธารณะรับจองหรือรับเงินจริงในสถานะนี้

## Cloudflare pilot วันที่ 5 ตุลาคม 2026

โหมด Worker ใช้ LINE ของเจ้าของแทนรหัสผ่านในเครื่อง ดูสถานะและขั้นตอนที่ README-CLOUDFLARE-FREE.md. เปิดหลังบ้านที่ `/miniapp?organizer=1` เพื่ออยู่ใต้ LIFF Endpoint เดิม; `/admin` จะเลือกหน้าให้ตามระบบ auth. คงระบบ local password เดิมไว้สำหรับเซิร์ฟเวอร์ในเครื่อง

Worker เตรียมการจอง/สลิป/ตรวจเงิน/เลือกคนเข้าสนามแล้ว แต่เริ่มต้นปิดรับจองจนกว่าเจ้าของจะผูก LINE ตั้งบัญชี และเปิดรับเอง ระบบนี้ยังไม่รวมค่าคอม/ปฏิทินโค้ชจริง/คืนเงินหรือ OCR บน Worker ข้อความเกี่ยวกับ local development ด้านบนไม่ได้ยืนยันสถานะ Worker
