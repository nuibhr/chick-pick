# Chick&Pick — ระบบเรียนกับโค้ช

พัฒนาต่อจาก `nuibhr/Chicken-ball` สาขา `redesign-marketplace-ux` commit `b2879952df90e24a4403495aa2068dc92ff89cc9` โดยใช้เอกสารแนบเป็นข้อมูลอ้างอิง โค้ดใน repository อาจไม่ตรงกับฟีเจอร์ทั้งหมดที่เอกสารเดิมอธิบาย

## เปิดใช้งาน

ใช้ Node.js 22 ขึ้นไป ติดตั้งด้วย `npm install` แล้ว `npm run dev` เปิด http://localhost:3000/?coaching=1

หรือใช้ `pnpm install` และ `pnpm dev` มี pnpm-lock.yaml ให้แล้ว หาก pnpm แจ้ง ignored build scripts ให้ตรวจสอบแพ็กเกจก่อนอนุญาตด้วย `pnpm approve-builds` ตามสภาพแวดล้อม

## สิ่งที่เพิ่ม

- แท็บเรียนกับโค้ช: โปรไฟล์ตัวอย่าง 3 คน ราคาและคอร์สแยกตามโค้ช
- สมัครเรียนส่วนตัวรายชั่วโมง (1–4 ชั่วโมง ครั้งละ 30 นาที) หรือซื้อคอร์ส
- คำนวณราคาฝั่งเซิร์ฟเวอร์ ป้องกันการแก้ยอดจากหน้าเว็บ
- การเรียนของฉัน: แสดงชั่วโมงพร้อมนัด นัดแล้ว และเรียนแล้ว
- หน้าโค้ช: ยอดรับเงิน/รอรับเงิน บันทึกเงินสดหรือโอนเต็มจำนวน และประวัติการรับเงิน
- นัดเรียน: ป้องกันเวลาโค้ชซ้อนกันและการใช้ชั่วโมงเกินสิทธิ์ ยกเลิกแล้วคืนชั่วโมง
- บันทึกสอนแล้วได้เมื่อสิ้นสุดเวลานัดเท่านั้น ไม่หักชั่วโมงซ้ำ
- เก็บข้อมูลฝั่งเซิร์ฟเวอร์ใน `data/coaching.json` ซึ่งไม่รวมใน Git

## วิธีลอง

1. เลือกโค้ช เลือกรายชั่วโมงหรือคอร์ส กรอกชื่อและเบอร์ตัวอย่าง
2. เปิด “จัดการสำหรับโค้ช” เลือกเงินสด/โอน แล้วกดยืนยันรับเงิน (ทดลอง)
3. เปิด “การเรียนของฉัน” เลือกวันเวลาอนาคตและจำนวนชั่วโมง นัดเรียน
4. ลองนัดเวลาทับกัน ระบบจะปฏิเสธ ลองยกเลิกแล้วชั่วโมงจะคืน
5. รีเฟรชหรือเริ่มเซิร์ฟเวอร์ใหม่ รายการยังอยู่

## ขอบเขต

เป็น local development preview ยังไม่ใช่ระบบรับเงินจริง ข้อมูลทุกคนใช้ร่วมกันและสามารถสลับหน้าผู้เรียน/โค้ชได้โดยไม่มี login จึงปิด API โค้ชทั้งหมดใน production (HTTP 503) จนกว่าจะเชื่อม authentication, ownership/role authorization และ payment verification ที่เหมาะสม ห้ามเปิด development server ให้สาธารณะ

ค่าตัวอย่างเป็นค่าเรียนส่วนตัว 1 คน ไม่รวมสนาม ไม่มีวันหมดอายุคอร์ส ไม่มีการชำระบางส่วน/คืนเงิน/อัปโหลดสลิป/จัดตารางเวลาว่างของโค้ช หน้านัดป้องกันเวลาชนกันแต่ยังไม่จำกัดเวลาทำงานของโค้ช วันที่แสดงตามเขตเวลาของอุปกรณ์

ข้อมูล JSON เหมาะกับเซิร์ฟเวอร์เครื่องเดียว ก่อนใช้จริงควรเปลี่ยนเป็นฐานข้อมูลพร้อม transaction และสำรองข้อมูล รวมทั้งเชื่อมบทบาทผู้ใช้งาน การตั้งราคา การจองสนาม นโยบายยกเลิกและคืนเงิน ระบบเดิมนอกโมดูลโค้ชยังคงขอบเขตการทำงานเดิม
